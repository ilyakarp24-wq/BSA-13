| Поле                      | Значение                                                                                                                                                                                                         |
| :------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Идентификатор**         | TST-UC02-NEG-000003                                                                                                                                                                                              |
| **Название**              | Попытка удаления смены с активной записью клиента                                                                                                                                                                |
| **Приоритет**             | Высокий                                                                                                                                                                                                          |
| **Предусловие**           | Менеджер авторизован. Находится на вкладке “Расписание”. В системе есть мастер с установленным рабочим днем, в котором есть хотя бы одна активная запись.                                                        |
| **Менеджер (сущность)**   | Сотрудник с ролью “Менеджер”                                                                                                                                                                                     |
| **Шаги**                  | 1. Менеджер находит смену нужного мастера в календаре.<br>2. Нажимает “Удалить смену”.                                                                                                                           |
| **Ожидаемый результат**   | • Система отменяет удаление.<br>• Выводится предупреждение: «Невозможно удалить смену, так как в этот период есть 1 подтвержденный визит. Перенесите или отмените визит клиента».<br>• Смена остается в системе. |
| **Постусловия**           | Модальное окно подтверждения удаления закрыто. Смена визуально присутствует в календаре. Визит клиента не затронут. Система предотвратила удаление родительской записи. Событие логировано.                      |
| **Фактический результат** | Заполняется после тестирования. Вносится ожидаемый результат, либо отчет о дефекте.                                                                                                                              |
