| Поле                      | Значение                                                                                                                                                                                                                                                                                                         |
| :------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Идентификатор**         | BRP-UC02-000001                                                                                                                                                                                                                                                                                                  |
| **Название**              | При закреплении слота за мастером система не сохраняет созданный слот в расписании мастера: визуально слот остается свободным и доступным для выбора                                                                                                                                                             |
| **Приоритет**             | Высокий                                                                                                                                                                                                                                                                                                          |
| **Важность**              | Critical (дефект создает невозможность записи на выбранное время)                                                                                                                                                                                                                                                |
| **Предусловие**           | Менеджер авторизован и находится в системе. В системе есть мастер с установленным рабочим днем. В выбранное время отсутствуют записи или другие слоты.                                                                                                                                                           |
| **Шаги**                  | 1. Менеджер заходит на вкладку “Расписание”.<br>2. Выбирает дату и временной интервал, нажимает “Создать слот”.<br>3. Выбирает мастера для связи со слотом, нажимает “Прикрепить”.<br>4. Подтверждает выбор.                                                                                                     |
| **Ожидаемый результат**   | Система создает слот с указанной датой, временным интервалом, привязанным мастером. Слот доступен для записи, находится в статусе “Свободен”.                                                                                                                                                                    |
| **Фактический результат** | Система не закрепляет слот за мастером, слот остается доступным для закрепления, не отображается в расписании и не доступен для записи клиентов.                                                                                                                                                                 |
| **Постусловия**           | Слот свободен и доступен для закрепления.                                                                                                                                                                                                                                                                        |
| **Окружение**             | • ОС: Windows 10 Pro.<br>• Браузер: Google Chrome 128.0.0.<br>• Разрешение: 1920x1080.<br>• Сеть: Корпоративный интернет 100 Мбит/с.                                                                                                                                                                             |
| **Описание**              | При создании ручного слота менеджер выполняет все действия согласно UC02, система не возвращает явной ошибки, однако транзакция записи в базу данных не фиксируется. Это приводит к рассинхронизации: менеджер уверен, что слот создан, и ожидает бронирования, в то время как клиенту он недоступен для записи. |
