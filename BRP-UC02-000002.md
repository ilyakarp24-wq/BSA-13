| Поле                      | Значение                                                                                                                                                                                                                                                                                                                      |
| :------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Идентификатор**         | BRP-UC02-000002                                                                                                                                                                                                                                                                                                               |
| **Название**              | При закреплении слота за мастером система сообщает, что выбранный слот забронирован в системе клиентом. Однако при обращении к клиенту тот отрицает, что забронировал этот слот.                                                                                                                                              |
| **Приоритет**             | Высокий                                                                                                                                                                                                                                                                                                                       |
| **Важность**              | Critical (менеджер вынужден записывать клиента на другое время, что ведет к неэффективному использованию сетки)                                                                                                                                                                                                               |
| **Предусловие**           | Менеджер авторизован и находится в системе. В системе есть мастер с установленным рабочим днем. В выбранное время отсутствуют записи или другие слоты.                                                                                                                                                                        |
| **Шаги**                  | 1. Менеджер заходит на вкладку “Расписание”.<br>2. Выбирает дату и временной интервал, нажимает “Создать слот”.<br>3. Выбирает мастера для связи со слотом, нажимает “Прикрепить”.<br>4. Подтверждает выбор.                                                                                                                  |
| **Ожидаемый результат**   | Система создает слот с указанной датой, временным интервалом, привязанным мастером. Слот доступен для записи, находится в статусе “Свободен”.                                                                                                                                                                                 |
| **Фактический результат** | Система выводит модальное окно с ошибкой: «Ошибка: выбранный слот забронирован в системе клиентом». Слот не закрепляется за менеджером. При поиске в базе данных по указанному времени и мастеру запись клиента отсутствует. При звонке клиенту, имя которого система могла бы вывести в ошибке, тот отрицает наличие записи. |
| **Постусловия**           | Слот остается визуально свободным, но фактически заблокирован для работы менеджера.                                                                                                                                                                                                                                           |
| **Окружение**             | • ОС: Windows 10 Pro.<br>• Браузер: Google Chrome 128.0.0.<br>• Разрешение: 1920x1080.<br>• Сеть: Корпоративный интернет 100 Мбит/с.                                                                                                                                                                                          |
| **Описание**              | В системе происходит рассинхронизация состояния. Механизм проверки доступности слота обращается к кэшу, который возвращает «фантомную» запись о клиенте, которой нет в основной таблице. Проблема может быть вызвана незавершенной транзакцией другого процесса или багом в алгоритме исключения дублей.                      |
