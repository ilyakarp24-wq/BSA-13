| :------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Идентификатор**         | TST-UC02-NEG-000004                                                                                                                                                                                                                                                      |
| **Название**              | Попытка создания слота поверх существующего клиентского визита                                                                                                                                                                                                           |
| **Приоритет**             | Высокий                                                                                                                                                                                                                                                                  |
| **Предусловие**           | Менеджер авторизован. Находится на вкладке “Расписание”. В системе есть мастер с установленным рабочим днем, в котором есть хотя бы одна активная запись со статусом “Зарезервирован”.                                                                                   |
| **Менеджер (сущность)**   | Сотрудник с ролью “Менеджер”                                                                                                                                                                                                                                             |
| **Шаги**                  | 1. Менеджер находит смену нужного мастера в календаре.<br>2. Выбирает время с активной записью.<br>3. Нажимает “Создать слот”.<br>4. Выбирает этого же мастера для закрепления за слотом.<br>5. Нажимает “Закрепить”.                                                    |
| **Ожидаемый результат**   | • Система отклоняет запрос.<br>• Кнопка «Подтвердить» остается неактивной или при нажатии выдает модальное окно с ошибкой: «Ошибка: слот занят визитом клиента N. Выберите другое время».<br>• В сетке расписания слот остается помеченным как «Забронировано клиентом». |
| **Постусловия**           | • Сетка расписания не изменилась. Слот сохраняет статус “Зарезервирован”. Никакой новой записи не создано.<br>• В логах зафиксирована ошибка. Транзакция БД отменена.                                                                                                    |
| **Фактический результат** | Заполняется после тестирования. Вносится ожидаемый результат, либо отчет о дефекте.                                                                                                                                                                                      |
